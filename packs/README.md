# Resource packs

## portalcraft-voxel-gun

Portal's handheld portal device rebuilt in voxels for Steve's hand: large voxels for the body, fine
ones for the details, with the firing, pick-up, release and fizzle poses, the draw motion, and the glow zones the mod drives
(`portalcraft:fire_frame`, `portalcraft:gun_glow`). In another player's hand, and in Portal's views
of Steve, it falls back to the mod's own light model (`portal_gun_third`).

To use it, copy the `portalcraft-voxel-gun` folder into your instance's `resourcepacks` folder and
enable it in Minecraft's resource pack screen.

It is generated by `tools/voxelize_portalgun_micro.py --v2` from the gun model in your own
copy of Portal; `tools/preview_item_micro.py` renders a pack's item model to a PNG for a quick look.
